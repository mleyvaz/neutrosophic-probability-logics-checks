# Provenance and license notices

The original files were copied from the supplementary directory associated
with *Complete probability logics for neutrosophic triples: a response to
Rivieccio's completeness question*. The originating project stores that
directory under `papers/completeness_neutrosophic_probability_logic/`.

`scripts/completeness_checks.py` is the original script, without edits.
`reference_results/completeness_checks.json` and
`reference_results/completeness_log.txt` are the original archived numerical
outputs, dated 1 October 2026 in the supplementary documentation.
Their SHA-256 digests are recorded in `source_manifest.json`.

The original supplementary README specifies **CC BY 4.0**. The parent
project's root LICENSE specifies **MIT**, with copyright attributed to
Maikel Yelandi Leyva Vázquez. Both notices have been retained: the specific
supplementary notice in `LICENSE`, and the verbatim parent license in
`licenses/UPSTREAM_MIT.txt`. The original files have no individual license
headers. The publication metadata follows the supplementary notice; it does
not assert that the original script was written jointly by both article
authors or silently replace the parent copyright attribution.

Added for this standalone package: `scripts/run_checks.py`,
`scripts/verify_results.py`, README, requirements, citation/deposit metadata,
and this provenance/manifest documentation. `results/` contains the fresh
verification run and its environment information. The release version is
`1.0.0`; it is a package version, distinct from the manuscript version.

The manuscript, private editorial reviews, coauthor correspondence, account
information, bibliography-network lookup scripts, and historical drafts
are not part of this reproducibility package. DOI and repository URL fields
are intentionally absent until a public repository and deposit exist.
